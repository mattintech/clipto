📖 Clipto Connection & Usage Guide

When do I need a tunnel?

  • Same Wi-Fi / Local Network: No tunnel needed! Use the Network: http://192.168.x.x address or scan the Phone QR code.
  • Cellular Data / Remote Cloud VM: Start with clipto --tunnel for an instant encrypted public HTTPS address reachable from anywhere.
  • SSH Port Forwarding: If already SSH'd into your server, forward the port locally without tunnels: 
    ssh -N -L 8765:localhost:8765 user@remote

How does session security work?

  • Automatic PIN: When using --tunnel or --pin, Clipto generates a 4-digit PIN to block internet crawlers.
  • Zero-Typing Magic Link: Your terminal link and QR code already have ?k=PIN embedded, logging you in instantly without typing!
  • Brute-Force Protection: After 5 failed attempts in 1 minute, the server locks out the client with HTTP 429.

Pro Tips & AI Workflows

  • Instant Paste: Smash Cmd+V anywhere on the page—no clicks needed.
  • Thumbnail Grid: Click any thumbnail image to inspect it full-screen in a lightbox.
  • AI Agent One-Shot Mode: 
    FILE=$(clipto --once --timeout 120)
    Waits for your screenshot, saves it, and outputs the path directly to your AI agent!

📋 Clipboard & Security Info

Modern web browsers restrict the Clipboard API to Secure Contexts (HTTPS or localhost). When accessing Clipto over plain HTTP across your local network (e.g. http://192.168.x.x:8765), browsers block reading and automatic clipboard copying for privacy.

How to enable full clipboard access:

1
Start Clipto with HTTPS (Self-Signed Cert): 
clipto --self-signed
Generates a local TLS cert for your LAN and Tailscale IPs so your browser grants secure clipboard privileges.
2
Or use an encrypted Cloudflare tunnel: 
clipto --tunnel
Gives you an automatic public HTTPS link with trusted certificates anywhere in the world.
3
Or connect via localhost:

If you are on the host computer, navigate to http://localhost:8765 instead of the LAN IP.

⌨
Manual Keyboard Shortcuts:

You can always paste manually using Cmd+V / Ctrl+V into the editor, or select text and press Cmd+C / Ctrl+C to copy.
